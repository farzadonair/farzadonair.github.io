# farzadonair

Nederlandse oefensite voor de basismodule mobiliteit. 241 vragen, interactieve bandenonderdelen, bandencodes en quizmuziek. Gemaakt door FARZAD.

## Publiceren met GitHub Pages

1. Maak in het account `farzadonair` een openbare repository met de naam `farzadonair.github.io`. Initialiseer deze met een README.
2. Plaats de inhoud van dit pakket rechtstreeks in de hoofdmap van de repository. `index.html` moet in de hoofdmap staan; behoud ook de map `assets` en het bestand `.nojekyll`.
3. Open Settings → Pages → Build and deployment. Kies Deploy from a branch, branch `main`, map `/ (root)` en Save.
4. Wacht op een geslaagde Pages-publicatie. De verwachte URL is `https://farzadonair.github.io/`; dit pakket is op zichzelf nog geen publicatie.
5. Controleer de optie Enforce HTTPS zodra die beschikbaar is.

Geen installatie, buildopdracht, database of API-sleutel nodig. Links en bestanden gebruiken relatieve paden. De bestaande Sites-publicatie blijft beschikbaar tijdens de overstap.

## Beveiliging en gegevens

Antwoorden worden niet naar een server verstuurd. De Content Security Policy in index.html blijft actief. GitHub Pages verwerkt het bestand `_headers` niet; de aanvullende HTTP-beveiligingsheaders van de eerdere hosting worden daarom niet automatisch overgenomen. Het bestand blijft beschikbaar voor hosting die deze configuratie wel ondersteunt.

Het werkboek en de bijbehorende afbeeldingen maken deel uit van deze bestaande oefensite. De oefenvragen zijn geen officiële toets.
